# برنامهٔ لانچر اندروید ممدکرفت

> این فایل از روی خواندن کد پروژه نوشته شده، نه از تست روی گوشی. هر چیزی که «باید تست شود» هنوز تست نشده.

## وضعیت

- [x] ۱. اسم (MamadCraft) و آیکون M
- [x] ۲. دو APK جدا: ۳۲ بیتی (armeabi-v7a) و ۶۴ بیتی (arm64-v8a)، بدون نسخهٔ x86
- [x] ۳. رنگ نارنجی، عکس روباه در صفحهٔ اصلی، دکمهٔ Play نارنجی
- [ ] ۴. ساده کردن قدم‌های شروع و انتخاب نسخه
- [ ] ۵. حالت «سبک» برای گوشی ۳۲ بیتی و رم کم
- [ ] ۶. گزینهٔ «نسخهٔ سبک» با Fabric و مودهای سبک‌ساز
- [ ] ۷. اضافه شدن سرور ممدکرفت به لیست
- [ ] ۸. چت و تعداد آنلاین (با Nhost)
- [ ] ۹. بخش Credits / لایسنس (LGPL-3.0)

## الان چند قدم تا بازی؟ (از روی کد)

بار اول:
1. ورود به حساب (مایکروسافت یا حساب آفلاین)
2. زدن روی لیست نسخه‌ها پایین صفحه و «ساخت پروفایل»
3. انتخاب نوع (Vanilla، Fabric، Quilt، Forge، NeoForge، OptiFine، مودپک)
4. انتخاب نسخهٔ ماینکرفت (و نصب مدلودر، اگه انتخاب شده)
5. برگشتن و انتخاب پروفایل
6. زدن Play (بار اول، دانلود نسخه و باز کردن Java قبل از شروع بازی)

بار دوم به بعد: فقط انتخاب پروفایل و Play (۲ قدم).

## تنظیمات فعلی برای گوشی کم‌رم (از روی کد)

- رم پیش‌فرض بازی: زیر ۱ گیگ → ۲۹۶ مگ، زیر ۱.۵ گیگ → ۴۴۸ مگ، زیر ۲ گیگ → ۶۵۶ مگ. گوشی ۳۲ بیتی بالای ۲ گیگ حداکثر ۶۹۶ مگ.
- رزولوشن: اگه گوشی قوی نباشه، هدف ۷۲۰ پیکسل (قوی یعنی اندروید ۱۰+، بیشتر از ۴ گیگ رم، صفحهٔ ۱۰۸۰+ و بیشتر از ۴ هسته).
- لانچر خودش به Sodium هشدار می‌ده (چون روی رندررهای موبایل مشکل داره). پس Sodium رو پیش‌فرض نمی‌ذاریم.

## ۴. ساده کردن شروع

- صفحهٔ اول: فقط اسم بازیکن (حساب آفلاین) و دکمهٔ «شروع».
- یه پروفایل آماده (نسخهٔ پیش‌فرض ممدکرفت) خودکار ساخته و انتخاب بشه.
- هدف: بار اول ۳ قدم (اسم، شروع، Play).

## ۵. حالت سبک (۳۲ بیتی / رم کم)

- نوشتن `options.txt` اولیه برای پروفایل: فاصلهٔ دید کم، گرافیک Fast، ابرها و ذرات و سایه‌ها کم، FPS محدود.
- رزولوشن پیش‌فرض پایین‌تر برای گوشی ضعیف.
- پیشنهاد نسخه‌های سبک‌تر ماینکرفت برای ۳۲ بیتی (مثل 1.8.9 و 1.12.2).
- آرگومان‌های جاوا برای رم کم (باید تست بشه).
- دکمهٔ «حالت سبک» توی تنظیمات.

## ۶. نسخهٔ سبک با Fabric

- یه دکمه که Fabric رو نصب کنه و مودهای سبک‌ساز رو از Modrinth بذاره.
- مودهای پیشنهادی برای تست: Lithium، FerriteCore، (Sodium فقط اگه روی رندرر موبایل جواب داد).
- فقط برای نسخه‌های جدیدتر. نسخه‌های قدیمی به OptiFine نیاز دارن.
- **باید روی گوشی واقعی تست بشه.**

## ۸. چت و آنلاین

- چت: همون جدول‌ها و حساب‌های Nhost سایت.
- تعداد بازیکن‌های سرور: چک وضعیت سرور (مثل سایت).
- تعداد کاربرهای لانچر: یه جدول کوچیک تو Nhost (SQL رو می‌نویسم، اجرا با تو).

## یادآوری‌ها

- لایسنس LGPL-3.0 و اسم سازنده‌های اصلی (Amethyst / PojavLauncher) باید بمونه، و سورس نسخهٔ ما عمومی بمونه.
- ورود مایکروسافت رو حذف نکن.
- APKها با نسخهٔ Debug ساخته می‌شن (امضای خود پروژه). برای انتشار جدی‌تر باید کلید امضای خودت رو بسازی.
